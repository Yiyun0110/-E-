## 三、标签合规性自查清单

| 法定标注项 | 法规要求 | 是否已包含 |
|-----------|---------|-----------|
| 产品名称 | 商标名+通用名+属性名 | ✅ |
| 备案人/生产企业名称和地址 | 真实有效 | ✅（待填） |
| 化妆品生产许可证编号 | — | ✅（待填） |
| 产品执行标准编号 | — | ✅（待填） |
| 全成分表 | 按含量降序，INCI/中文名 | ✅（按实际含量调整顺序） |
| 净含量 | 50g | ✅ |
| 使用期限/生产批号 | 二者选一或共存 | ✅（见包装标注） |
| 使用方法 | 驻留类需说明 | ✅ |
| 安全警示用语 | 必要时标注 | ✅ |
| 贮存条件 | 必须标注 | ✅ |
| 备案编号 | 备案后生成 | 备案后补充 |

## 四、销售包装图片要求

备案时需上传以下图片：
- [ ] 产品平面图（正面、背面）
- [ ] 产品立体图
- [ ] 如有说明书，需提供说明书内容

> ⚠️ **重要提示：**
> - 成分表中各成分应按 **实际含量从高到低** 降序排列（上述为示例，请按实际配方调整顺序）
> - 上述成分列表中，鲸蜡硬脂基葡糖苷来自Montanov 68，甘油硬脂酸酯和PEG-100硬脂酸酯来自A165——备案时 **以单体成分列出** 而不是以复合商品名列出（如上所示）
> - 包装设计稿需提供高清图片（建议300dpi以上）
