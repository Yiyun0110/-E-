# 化妆品备案——准备清单与操作说明

## 一、备案流程总览

```
注册备案平台账号 → 填写产品信息 → 上传电子资料 → 提交备案 → 系统自动生成备案编号 → 备案完成 → 产品可上市
       │
       └── 资料存档备查（无需纸质提交）
```

备案平台：国家药监局化妆品注册备案信息服务平台
https://zwfw.nmpa.gov.cn

> 自2024年9月起，全面实施电子备案，提交完整符合要求的资料即完成备案，无需审批，产品可上市销售。

## 三、产品名称命名依据

### 命名规则（依据《化妆品命名规定》）

**「商标名 + 通用名 + 属性名」**

| 组成 | 说明 | 示例 |
|------|------|------|
| 商标名 | 已注册商标或品牌名 | [品牌名] |
| 通用名 | 表明产品主要成分或功能 | 尿素保湿修复 |
| 属性名 | 表明产品物理性状或剂型 | 霜 |

### 建议名称示例

> **[品牌名] 尿素保湿修复霜**
>
> 命名依据：
> - 商标名：[品牌名]，为已注册商标/企业品牌
> - 通用名："尿素保湿修复"，表明产品的核心功效成分（尿素）和产品功能定位（保湿、修复皮肤屏障）
> - 属性名："霜"，表明产品为膏霜类剂型
>
> 产品名称未违反《化妆品命名规定》中的禁止性条款，符合要求。

### 命名注意事项

- ❌ 不得使用医疗术语（如"治疗""治愈""疗效"）
- ❌ 不得使用夸大词（如"特效""万能""换肤"）
- ❌ 不得暗示医疗效果（如"消炎""杀菌""抗敏"）
- ✅ 可使用"保湿""滋润""修护""滋养"等化妆品功效用语
- ✅ 可使用原料名称作为通用名（"尿素"属于已使用的化妆品原料）

### 建议送检项目

| 检测类别 | 具体项目 |
|---------|---------|
| 微生物检验 | 菌落总数、霉菌酵母菌、耐热大肠菌群、金葡、铜绿 |
| 理化检验 | pH、耐热、耐寒、离心稳定性 |
| 重金属 | 汞、铅、砷、镉 |
| 甲醇 | 甲醇含量 |
| 防腐挑战 | 防腐体系有效性评价 |
| 稳定性试验 | 长期+加速（3-6个月数据） |

## 五、常见问题及注意事项

### 关于"甲酯+丙酯"防腐剂
- 羟苯甲酯（甲酯）和羟苯丙酯（丙酯）属于尼泊金酯类防腐剂
- 《化妆品安全技术规范》规定：单一酯≤0.4%，混合酯总量≤0.8%
- 尽管尼泊金酯安全性在CIR评估中已确认，但建议控制用量尽可能低
- ⚠️ 注意：2026年已禁用部分尼泊金酯类在某些产品中的应用，需保持关注法规更新

### 关于苯氧乙醇
- 限值≤1.0%，是化妆品中最广谱的防腐剂之一
- 具有轻微特征性气味，注意用量

### 关于IPM
- 肉豆蔻酸异丙酯虽然肤感好，但有一定致粉刺性
- 建议用于尿素霜（非面部专用）时控制用量≤5%
- 如产品主诉"不致粉刺"，建议使用替代油脂

### 关于完整版安全评估报告（2025年新规）
- 自2025年5月1日起，不再接受简化版安全评估报告
- 完整版必须包含：防腐挑战测试、稳定性评估、包材相容性评估
- 评估人员需具有5年以上相关从业经历

### 关于功效宣称（保湿）
- 如需在标签上标注"保湿"功效，需提供功效评价依据
- 可以引用已发表的文献数据，或进行人体功效评价试验
- 尿素本身就是公认的保湿成分，可通过文献资料支撑
