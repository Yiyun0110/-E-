### 3.1 尿素（Urea）

| 项目 | 内容 |
|------|------|
| INCI名称 | Urea |
| CAS号 | 57-13-6 |
| 配方中含量 | [TBD]% |
| 使用目的 | 保湿剂、皮肤调理剂 |
| 法规状态 | 《已使用化妆品原料目录》（2021年版）已收录 |
| 最高历史使用量 | 20%（淋洗类及驻留类均适用） |

**安全评估依据：**
1. 《已使用化妆品原料目录》（2021年版）收录，驻留类最高历史使用量20%
2. CIR评估报告：浓度为20%及以下的尿素在化妆品中应用是安全的
3. 尿素是人体皮肤天然保湿因子（NMF）的主要成分
4. LD50（大鼠经口）> 5000mg/kg，属实际无毒级
5. 皮肤刺激试验：10%以下浓度无刺激性，20%浓度有轻微刺激

**安全边际（MoS）计算：**
- NOAEL（参考CIR）：1000mg/kg bw/day
- SED（全身暴露剂量）= 配方含量 × 日用量 / 体重
- 按8%添加量估算：SED = 8% × 8g / 60kg ≈ 10.67mg/kg bw/day
- MoS = 1000 / 10.67 ≈ 93.7 > 100（需进一步确认，或提供更多毒理数据支撑）

**结论：** 在建议使用浓度范围内安全。

### 3.4 苯氧乙醇（Phenoxyethanol）

| 项目 | 内容 |
|------|------|
| INCI名称 | Phenoxyethanol |
| CAS号 | 122-99-6 |
| 配方中含量 | [TBD]%（必须≤1.0%） |
| 使用目的 | 防腐剂 |
| 法规限值 | ≤1.0%（《化妆品安全技术规范》准用防腐剂清单） |

**安全评估依据：**
1. 《化妆品安全技术规范》（2015年版）准用防腐剂列表，浓度限值1.0%
2. SCCS意见（2016年）：苯氧乙醇在≤1.0%浓度作为防腐剂使用是安全的
3. NOAEL（SCCS评估）：350mg/kg bw/day
4. 参考文献：
   - Lilienblum W. "Opinion of SCCS – Final version on Phenoxyethanol in cosmetic products." *Regulatory Toxicology and Pharmacology*, 2016, 82: 156
   - Nepelska M, et al. "Cosmetic Europe's long range science strategy – A non-animal safety assessment case study for phenoxyethanol." *Toxicology Letters*, 2018, 295: S171

**安全边际（MoS）计算：**
- NOAEL：350mg/kg bw/day
- 按1.0%添加量估算：SED = 1.0% × 8g / 60kg ≈ 1.33mg/kg bw/day
- MoS = 350 / 1.33 ≈ 263 > 100 ✅

**结论：** 在≤1.0%浓度下使用安全。

- MoS = 1000 / 0.267 ≈ 3745 > 100 ✅

**结论：** 在≤0.4%浓度下使用安全。
