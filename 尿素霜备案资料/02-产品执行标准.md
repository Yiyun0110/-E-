## 三、生产工艺简述

### 3.1 工艺流程图

```
A相（油相）：1618醇 + Montanov 68 + A165 + 霍霍巴油 + ININ + IPM + GTCC + DC200/350 + 2EHP + 维生素E
    ↓ 加热至75-80℃溶解均匀
B相（水相）：纯化水 + 甘油 + 丙二醇 + EDTA二钠 + 卡波姆940
    ↓ 加热至75-80℃溶解均匀
A相加入B相 → 均质乳化（75-80℃，3000-5000rpm，15-20min）
    ↓ 冷却
降温至45-50℃ → 加入尿素、尿囊素（预溶）→ 搅拌
    ↓ 冷却
降温至≤40℃ → 加入苯氧乙醇、羟苯甲酯、羟苯丙酯 → 搅拌
    ↓
加入黄原胶 → 调整稠度 → 均质脱泡
    ↓
检验合格 → 静置陈化24h
    ↓
灌装、封口、包装
```

### 3.2 详细操作步骤

**步骤一：油相（A相）制备**
将鲸蜡硬脂醇（1618醇）、Montanov 68（鲸蜡硬脂醇/鲸蜡硬脂基葡糖苷）、A165（甘油硬脂酸酯/PEG-100硬脂酸酯）、霍霍巴籽油、ININ（异壬酸异壬酯）、IPM（肉豆蔻酸异丙酯）、GTCC（辛酸/癸酸甘油三酯）、DC200/350（聚二甲基硅氧烷）、2EHP（棕榈酸乙基己酯）、维生素E依次投入油相锅中，搅拌加热至75-80℃，使所有油相原料完全溶解混合均匀。

**步骤二：水相（B相）制备**
将纯化水加入水相锅中，加入甘油、丙二醇、EDTA二钠、卡波姆940，搅拌分散均匀，加热至75-80℃，确保完全溶解/分散。

**步骤三：乳化**
在搅拌状态下，将A相（油相）缓慢加入B相（水相）中。开启均质器，以3000-5000rpm均质乳化3-5分钟。然后在75-80℃条件下，以搅拌速度100-300rpm持续搅拌15-20分钟，使乳化体系充分均质。

**步骤四：降温**
开启冷却循环水，将乳化体系降温至45-50℃。

**步骤五：加入活性成分**
将尿素和尿囊素用少量纯化水预溶解后，加入体系中，以100-200rpm搅拌速度搅拌均匀。

**步骤六：加入防腐剂**
继续降温至40℃以下，依次加入苯氧乙醇、羟苯甲酯、羟苯丙酯，搅拌至均匀。

**步骤七：增稠调节**
加入黄原胶，调节至适宜稠度，搅拌均匀。

**步骤八：均质脱泡**
以1000-2000rpm低速均质2-3分钟，脱除气泡。

**步骤九：出料与陈化**
取样检验合格后出料，静置陈化24小时。

**步骤十：灌装**
经检验合格后，在洁净车间（10万级净化环境）中进行灌装、封口、包装。

## 九、使用方法

取适量本品均匀涂抹于清洁后的皮肤，轻轻按摩至吸收。建议每日使用1-2次。

**安全警示用语：**
- 本品仅限外用
- 避免接触眼睛，如不慎入眼请立即用大量清水冲洗
- 皮肤有破损处请勿使用
- 使用后如有不适，请立即停用并咨询医生
- 请置于儿童接触不到的地方
- 请于阴凉干燥处保存，避免阳光直射

## 十、贮存条件

常温、避光、密封保存。贮存环境温度应保持在0-40℃之间，相对湿度不超过80%。

## 十一、使用期限

产品保质期为 **3年** （36个月），在符合规定的贮存条件下，自生产之日起计算。
